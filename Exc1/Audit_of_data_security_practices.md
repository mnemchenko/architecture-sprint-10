# Аудит мер по обеспечению безопасности данных

- *Принцип минимальных привилегий не реализован: все имеют доступ ко всей информации.* Это ведет к большим инсайдерским рискам
- В организации не применяются политики классификации данных и, следовательно, не соответствуют нормативным требованиям закона (ФЗ-152)
- Учет персональных данных не ведется
- Не применяются специальные процедуры обработки и хранения для различных типов данных, включая конфиденциальные и критически важные
- Данные не шифруются как при передаче по сети, так и при хранении на уровне файловой системы
- Резервные копии не шифруются
- Доступ к резервным копиям не контролируется
- Тестирование восстановления из резервной копии не проводится
- Многофакторная аутентификация не применяется
- Регулярные аудиты учётных записей с повышенными привилегиями не проводятся
- Автоматическое удаление или деактивация учётных записей после увольнения сотрудников не выполняется
- Журналирование всех операций доступа к системам и данным не ведется
- Анализ логов для выявления аномалий или подозрительной активности не ведется
- Явное согласие пользователя перед сбором или обработкой персональных данных не требуется
- Не запрашивается отдельное согласие на обработку чувствительной медицинской информации в соответствии с нормативными актами
- Нет политики кинфиденциальности
- Персональные данные передаются там, где их можно не передавать – не используется принцип минимизации используемых данных для решения задачи
- Не предусмотрена процедура удаление персональных данных по просьбе клиента (ФЗ-152)
- Не предусмотрена процедура доступа к истории использования информации со стороны пользователя (ФЗ-152)
- Обучение сотрудников по работе с конфиденциальными данными не проводится
